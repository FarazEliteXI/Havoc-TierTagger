# Havoc TierTagger

A Minecraft Fabric mod that displays Havoc TierList player tiers in-game.

## Features
- In-game player tier nametags
- Tier information in the tab list
- Multiple gamemode support
- Player tier lookup
- Havoc TierList integration

## Requirements
- Minecraft 1.21.11
- Fabric Loader
- Fabric API

## Installation
1. Download the latest `.jar` from Releases.
2. Place it inside your Minecraft `mods` folder.
3. Launch Minecraft using Fabric.
